# The Faceless Studio — Project Archive & Handoff
**Operator:** Shaylee Carpenter · **Business email:** shaycrypto56@gmail.com · **Portfolio:** https://hyperagent.com/s/FMzW0cevuae9D2CofCVq0A

This repo is the disaster-recovery + handoff home for the faceless UGC business.
A successor agent (or human) starts here:

1. **`handoff/HANDOFF.md`** — the full operating manual (mission, accounts, rules, assets, pipelines, resume steps)
2. **`handoff/SESSION_STATE.md`** — latest session state & publish queue
3. **`handoff/POSTING_BOARD.md`** — the 14-post seasoning schedule: what to post, where, exact captions
4. **`handoff/asset_manifest.csv`** — every asset with IDs and public URLs
5. **`portfolio/portfolio_page.html`** — the live portfolio site source
6. **`pipeline/`** — the local production/verification toolchain (ffmpeg + faster-whisper)

Media binaries (videos, VO memos) ship as GitHub Releases (phase 2) — public URLs for all published videos are in the asset manifest meanwhile.
