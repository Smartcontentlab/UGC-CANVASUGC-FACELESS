How to record (iPhone)

  1. Voice Memos app · Settings → Voice Memos → Lossless on · airplane mode on.
  2. Quiet room — a closet full of clothes is a free studio. Phone 6–12" from your mouth, slightly off to the side.
  3. Say the file name at the start ("vo p one"), then do 2–3 takes back-to-back in the same memo. I'll pick the best.
  4. Tone: talking to a friend, slight smile — it's audible. A touch slower beats rushed. Within ~2s of target is perfect.
  5. Rename each memo to its file name (vo_p1, vo_d03…) before sending.
📤 Sending back: Voice Memos → share → Save to Files → attach all of them here in the chat (or the Google Drive folder if you enabled it). Any format works — m4a, mp3, wav.
